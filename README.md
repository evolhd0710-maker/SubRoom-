# 가사방

블루투스로 노래방 기기에 MR을 틀 때, 유튜브 MR에 맞춰 노래방처럼 가사를 띄워주는 웹사이트입니다.

- **자막 만들기**: 유튜브 MR 링크 → 가사 붙여넣기 → 재생하면서 소절마다 탭(스페이스바)으로 싱크
- **부르기 화면**: 노래방식 두 줄 표시, 가사 칠하기(와이프), 전주·간주 카운트다운, 블루투스 지연 보정, 전체화면
- **공유 대시보드**: 다른 사람이 만든 싱크 검색·부르기, 남의 싱크는 복사해서 편집
- **LRC 가져오기/내보내기**

파일은 `index.html` 하나에 전부 들어 있습니다. 빌드 과정이 없습니다.

## 1. 내 컴퓨터에서 실행

유튜브는 파일을 더블클릭해서(`file://`) 열면 재생을 막습니다. 반드시 웹 서버로 여세요.

```bash
cd gasabang
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

이 상태는 **로컬 모드**라서 만든 싱크가 그 브라우저에만 저장됩니다.

## 2. 인터넷에 올리기 (휴대폰에서 쓰기)

아래 중 아무거나 무료로 됩니다. 폴더를 그대로 올리면 끝입니다.

- **Netlify Drop**: app.netlify.com/drop 에 폴더를 끌어다 놓기
- **GitHub Pages**: 저장소에 올리고 Settings → Pages 켜기
- **Vercel / Cloudflare Pages**: 저장소 연결 후 배포 (빌드 명령 없음)

## 3. 공유 대시보드 켜기 (Supabase, 무료)

1. supabase.com 에서 새 프로젝트 만들기
2. **SQL Editor**에 `schema.sql` 내용을 붙여넣고 Run
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키 복사
4. `index.html` 위쪽 `CONFIG`에 붙여넣기

```js
const CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...'
};
```

다시 배포하면 상단의 "로컬 모드" 안내가 사라지고 대시보드가 모든 사용자에게 공유됩니다.

**권한 구조**: 로그인 없이 누구나 보고 올릴 수 있습니다. 곡을 올린 브라우저에 비밀 토큰이 저장되고, 그 토큰이 있어야만 수정·삭제가 됩니다. 다른 사람 곡은 "복사해서 편집"으로 내 곡을 새로 만듭니다. 로컬 모드에서 만든 곡은 서버로 자동 이전되지 않으니 LRC로 내보냈다가 다시 가져오세요.

## 사용 팁

- 가사 한 줄은 20자 안팎으로 끊어야 노래방처럼 보기 좋습니다.
- 싱크할 때 0.75× 속도로 틀면 훨씬 정확합니다. (재생 속도와 무관하게 실제 시간으로 기록됨)
- 간주 앞 소절은 노래가 끝나는 순간 **줄 끝(Enter)** 을 누르면 화면이 "간주 중"으로 넘어가고, 다음 소절 4초 전부터 카운트다운 점이 나옵니다.
- 블루투스 스피커는 보통 0.1~0.3초 늦게 소리가 나옵니다. 부르기 화면의 **소리 지연 +** 로 맞추면 기기에 저장됩니다.
- 업로더가 외부 재생을 막은 유튜브 영상은 재생되지 않습니다. 다른 MR 영상을 고르세요.

## 데이터 형식

```json
{
  "youtube_id": "11자리 영상 ID",
  "title": "곡 제목", "artist": "가수", "author": "싱크 작성자",
  "lines": [ { "t": 12.34, "e": null, "text": "가사 한 줄" } ]
}
```

`t`는 줄 시작(초), `e`는 줄 끝(초, 없으면 다음 줄 시작으로 계산). LRC와 서로 변환됩니다.

## 정식 서비스로 옮길 때

- 화면은 `viewDash` / `viewEditor` / `viewPlay` 세 함수, 저장은 `Store`(`list/get/save/remove/bump`) 하나로 분리되어 있어 React·Next.js 컴포넌트와 API로 그대로 옮기기 좋습니다.
- 로그인(Supabase Auth)을 붙이면 `owner_token` 대신 `auth.uid()`로 RLS를 바꾸면 됩니다.
- 가사 공개 공유는 저작권 이용허락(음저협 등) 확보 후 운영하세요.
